# 365-Day Journey Tracker

A personal 365-day learning and development tracker built to document my progress every day from **October 1, 2026 to September 30, 2027**.

The goal of this project is simple: **show up every day, learn something, build something, and keep a public record of the journey.**

## 🚀 Features

- 📅 Interactive 365-day calendar
- 📝 Add daily achievements and learning notes
- 📖 View everything completed on a specific date
- 🔐 Secure owner login for adding, editing, and deleting entries
- 🌍 Public access so anyone can follow the journey
- ☁️ Supabase database for storing daily progress
- 📊 Visual distinction between past, current, and future days
- 📱 Responsive design for desktop and mobile

## 🎯 Journey

**Start:** October 1, 2026  
**End:** September 30, 2027  
**Duration:** 365 days

Throughout these 365 days, I will use this tracker to document things such as:

- Learning new technologies
- Solving coding problems
- Building projects
- Improving development skills
- Reading and studying
- Exploring new tools
- Personal milestones related to my development journey

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Supabase
- GitHub
- Render

## 🔐 How It Works

The tracker uses Supabase as its backend.

Visitors can view the publicly recorded progress, while only the owner account can create, edit, or delete daily entries.

Each day can contain multiple achievements, allowing the tracker to become a complete timeline of the journey.

## 🌱 Why I Built This

This project is more than just a calendar. It is a commitment to consistency.

Instead of only setting goals, I want to create a public record of what I actually do every day.

**365 days. 365 opportunities to improve.**

> Show up. Learn. Build. Repeat.
